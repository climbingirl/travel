# Travel

Это современный одностраничный проект, посвящённый теме путешествий, реализованный с использованием HTML, SCSS и JavaScript. Проект демонстрирует навыки создания адаптивного, стильного и интерактивного сайта.

## GitHub Pages

[https://climbingirl.github.io/travel/](https://climbingirl.github.io/travel/)

## Функциональность

- **Адаптивный дизайн**  
  Сайт автоматически подстраивается под размер экрана устройства, обеспечивая комфортный просмотр на любых устройствах.

- **Интерактивные элементы и анимации**  
  Плавные анимации и эффекты делают взаимодействие с сайтом приятным и современным.

- **Бесконечный адаптивный слайдер**  
  В проекте реализован бесконечный слайдер, который автоматически подстраивается под ширину экрана и количество видимых слайдов. Слайдер плавно прокручивается по кругу, обеспечивая непрерывный просмотр изображений и контента без резких скачков.


## Технологии

- HTML5  
- SCSS  
- JavaScript (ES6+)
